# Two-Bit Alchemy

Two-Bit Alchemy is a personal identity and website project centered on curiosity, observation, craft, and patient transformation.

The current baseline is documented in `Two-Bit_Alchemy_Website_AI_Handoff.md`. That file remains the source handoff from ChatGPT and should be read before implementation decisions are made.

## Current Direction

- Two-Bit Alchemy is the umbrella identity.
- Fisher Aquatics becomes one project within that wider identity.
- The visual tone is Victorian natural-history engraving: grounded, handcrafted, and quietly mystical.
- The site should feel personal, exploratory, and durable rather than corporate or sales-focused.

## Development Status

Repository-controlled WordPress theme implementation is in progress.

No live WordPress content should be published or cleaned up without explicit approval. Theme packages should be built and validated from the repository before WordPress installation or update.
