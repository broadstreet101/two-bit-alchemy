# Content

Use this folder to draft and organize site content before templates are built.

## Areas

- `about/`
- `cabinet/`
- `field-notes/`
- `journal/`
- `media/`
- `philosophy/`
- `projects/`

Content can begin as Markdown drafts even if the final site remains WordPress-based.

`media/` holds approved web-ready derivatives used by repository-controlled content. Original source media belongs in the local ignored `media-archive/` folder.
